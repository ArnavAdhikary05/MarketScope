# Market data sources

The current provider adapter uses `yfinance` to retrieve OHLCV history. It is intended for educational research and does not guarantee real-time data, exchange entitlements, complete coverage, or production service levels. Provider limits and retention rules may change.

The adapter accepts Yahoo Finance symbols such as `AAPL` and `RELIANCE.NS` when the provider supports them. It normalizes column names, removes missing or structurally invalid OHLCV rows, sorts observations, and removes duplicate timestamps. It uses `auto_adjust=True`; the returned prices are adjusted according to yfinance behavior and should not be confused with unadjusted exchange prints.

Supported provider interval values include 1m, 5m, 15m, 30m, 60m, 1h, and 1d, subject to Yahoo's currently available history. The UI exposes daily, 5-minute, and 15-minute choices. Data freshness is reported as the timestamp of the last returned observation; this does not establish that the feed is live.

The forecasting service uses `pandas-market-calendars` for NYSE, NASDAQ, NSE, BSE, LSE, TSX, TSXV, ASX, HKEX, JPX, and XETR session closes. Automatic exchange resolution uses Indian ticker suffixes where possible and provider metadata for other symbols; if metadata lookup is unavailable, the user can choose an exchange explicitly. These calendars supply scheduled sessions, not live market-status or emergency-closure information. The market-history platform still does not use a licensed provider, retry policy, rate-limit coordinator, corporate-action store, or persistent bar cache. Multi-day model comparison requires daily bars; no intraday forecast timestamps are generated.

## News, sentiment, and factor snapshots

The sentiment endpoint tries Finviz news first and falls back to Yahoo Finance news if Finviz is unsupported or returns no usable timestamped articles. The user may request a 30- or 90-day analysis window; only recent items with parseable timestamps are retained. The API reports its selected source, fallback status, and retrieval time. Provider-specific availability, coverage, formats, and rate limits can change; responses are cached in process for 15 minutes and are not persisted to the database.

Groq classification is optional and requires `GROQ_API_KEY` in the backend environment. The backend sends article titles, summaries, timestamps, and ticker to Groq; the credential is sent only in the authorization header and is never included in response data or logs. If the key is absent or the provider fails, the news remains visible without AI labels. Sentiment is an AI interpretation, not a verified fact.

Sentiment is grouped by the listing exchange's local date. Correlation pairs a daily score with returns after the next scheduled exchange close, so the feature is not assigned to a return period that began before the news was available. Pearson p-values are nominal and do not adjust for serial dependence, repeated testing, or news selection. The result is correlation, not causation.

Yahoo Finance fundamentals are current snapshots, not historical point-in-time statements, and are excluded from forecast training. The forecast endpoint also retrieves the exchange's broad benchmark history when available, aligns its returns and rolling volatility backward to the stock's daily bars, and uses those lagged factors only in supervised machine-learning models. Missing benchmark data leaves the OHLCV-only pipeline available. Technical and volume factors are computed from observations available at each training origin; the latest known OHLCV and benchmark factors are held fixed for recursive future paths rather than inventing future data. Daily-bar VWAP and turnover are OHLCV proxies; bid-ask spread/order-book depth are not available. Macro, sector, FX, and corporate-event timestamp history are not configured and are reported unavailable.
